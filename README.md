# C++ Array Basics
This repository contains my C++ array practice programs ,developed while learning programming and Data Structure fundamentals.
## Topics Covered:
- Array declaration
- Taking input and display array elements
- Finding minimum and maximum
- sum subtraction and average of array elements
- counting even and odd numbers in array
- counting positive , negative and zero in array
- linear search
- sorting in ascending and descending order
- reversing an array
### Programming language
C++
